## Фоновое чтение (push-режим) в клиентской форме

Модуль управляемой формы: компонента читает топик в фоновом потоке и передаёт пакеты сообщений
в `ОбработкаВнешнегоСобытия`. Смещения фиксируются вручную после обработки пакета, поэтому
сообщение, не обработанное в 1С, будет прочитано повторно (гарантия «хотя бы один раз»).

Описание методов и событий — в разделе [Фоновое чтение (push-режим)](../consumer.md#фоновое-чтение-push-режим).

Пример рассчитан на платформу 8.3.18 и выше (`ПодключитьВнешнююКомпонентуАсинх`). Компонента
хранится в общем макете `SimpleKafka1C`. Push-режим работает только на клиенте: на сервере
обработчика внешних событий нет.

```1c
&НаКлиенте
Перем Компонента;

#Область ОбработчикиСобытийФормы

&НаКлиенте
Процедура ПриЗакрытии(ЗавершениеРаботы)

	Если Компонента <> Неопределено Тогда
		Компонента.ОстановитьФоновоеЧтение();
		Компонента.ОстановитьКонсьюмера();
	КонецЕсли;

КонецПроцедуры

&НаКлиенте
Процедура ОбработкаВнешнегоСобытия(Источник, Событие, Данные)

	Если Источник <> "SimpleKafka" Тогда
		Возврат;
	КонецЕсли;

	Если Событие = "Messages" Тогда
		ОбработатьПакет(Данные);
	ИначеЕсли Событие = "Error" Тогда
		ДобавитьВЖурнал("Ошибка Kafka: " + Данные);
	ИначеЕсли Событие = "Stopped" Тогда
		ДобавитьВЖурнал("Фоновое чтение остановлено: " + Данные);
	КонецЕсли;

КонецПроцедуры

#КонецОбласти

#Область ОбработчикиКомандФормы

&НаКлиенте
Асинх Процедура Запустить(Команда)

	Если Компонента = Неопределено Тогда
		Подключено = Ждать ПодключитьВнешнююКомпонентуАсинх("ОбщийМакет.SimpleKafka1C", "SimpleKafka",
			ТипВнешнейКомпоненты.Native);
		Если НЕ Подключено Тогда
			ДобавитьВЖурнал("Не удалось подключить компоненту");
			Возврат;
		КонецЕсли;
		Компонента = Новый("AddIn.SimpleKafka.SimpleKafka1C");
	КонецЕсли;

	// Ручная фиксация: смещение сохраняется только после обработки пакета в 1С
	Компонента.УстановитьПараметр("group.id", "push-monitor");
	Компонента.УстановитьПараметр("enable.auto.commit", "false");
	Компонента.УстановитьПараметр("enable.auto.offset.store", "false");

	Если НЕ Компонента.ИнициализироватьКонсьюмера("localhost:9092")
		ИЛИ НЕ Компонента.Подписаться("my-topic")
		ИЛИ НЕ Компонента.ЗапуститьФоновоеЧтение(50, 500, Ложь, 100) Тогда
		ДобавитьВЖурнал(Компонента.ПолучитьСообщениеОбОшибке());
		Возврат;
	КонецЕсли;

	ДобавитьВЖурнал("Фоновое чтение запущено");

КонецПроцедуры

&НаКлиенте
Процедура Остановить(Команда)

	Если Компонента <> Неопределено Тогда
		Компонента.ОстановитьФоновоеЧтение();
		ДобавитьВЖурнал("Фоновое чтение остановлено");
	КонецЕсли;

КонецПроцедуры

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

&НаКлиенте
Процедура ОбработатьПакет(Данные)

	ЧтениеJSON = Новый ЧтениеJSON;
	ЧтениеJSON.УстановитьСтроку(Данные);
	Пакет = ПрочитатьJSON(ЧтениеJSON);
	ЧтениеJSON.Закрыть();

	// Наибольшее смещение по каждой паре "топик + партиция"
	Позиции = Новый Соответствие;

	Для Каждого Сообщение Из Пакет.messages Цикл

		ДобавитьВЖурнал(СтрШаблон("%1[%2]@%3: %4", Сообщение.topic, Сообщение.partition,
			Формат(Сообщение.offset, "ЧГ=0"), Сообщение.message));

		КлючПозиции = Сообщение.topic + "|" + Формат(Сообщение.partition, "ЧГ=0");
		Позиция = Позиции.Получить(КлючПозиции);
		Если Позиция = Неопределено Или Позиция.Смещение < Сообщение.offset Тогда
			Позиции.Вставить(КлючПозиции, Новый Структура("Топик, Партиция, Смещение",
				Сообщение.topic, Сообщение.partition, Сообщение.offset));
		КонецЕсли;

	КонецЦикла;

	// Фиксируется смещение следующего сообщения, то есть последнее прочитанное + 1
	Для Каждого Элемент Из Позиции Цикл
		Позиция = Элемент.Значение;
		Если НЕ Компонента.ЗафиксироватьСмещение(Позиция.Топик, Позиция.Смещение + 1, Позиция.Партиция) Тогда
			ДобавитьВЖурнал("Ошибка фиксации: " + Компонента.ПолучитьСообщениеОбОшибке());
		КонецЕсли;
	КонецЦикла;

КонецПроцедуры

&НаКлиенте
Процедура ДобавитьВЖурнал(Текст)

	Журнал = Журнал + Формат(ТекущаяДата(), "ДФ='ЧЧ:мм:сс'") + " " + Текст + Символы.ПС;

КонецПроцедуры

#КонецОбласти
```

Реквизит формы `Журнал` (Строка, неограниченной длины) выводится многострочным полем.
Команды `Запустить` и `Остановить` привязаны к одноимённым процедурам.

### Проверка (чек-лист приёмки)

| № | Действие | Ожидаемый результат |
|---|---|---|
| AC-1 | `ЗапуститьФоновоеЧтение` без `ИнициализироватьКонсьюмера` | Ложь, `Consumer not initialized` |
| AC-2 | повторный `ЗапуститьФоновоеЧтение` | Ложь, `Push consumer is already running` |
| AC-3 | `МаксСообщенийВСобытии = 10`, отправить в топик 25 сообщений | события с суммарным `count = 25`, в каждом `count ≤ 10` |
| AC-4 | топик пуст, подождать 5 с | событий `Messages` нет |
| AC-5 | одно сообщение прочитать событием и `ЧитатьПакетСообщений` | элементы `messages` совпадают |
| AC-6 | `ГлубинаБуфераСобытий = 1`, открыть модальный диалог, отправить сообщения, закрыть диалог | пришли все сообщения |
| AC-7 | при запущенном чтении вызвать `ПрочитатьСообщение` | Ложь, `Push consumer is running` |
| AC-8 | `ОстановитьФоновоеЧтение` | Истина менее чем за 1 с, `ФоновоеЧтениеЗапущено() = Ложь`, синхронное чтение снова доступно |
| AC-9 | закрыть форму, не останавливая чтение | клиент не падает |
| AC-10 | ручная фиксация из примера | `ПолучитьСмещенияГруппыКонсьюмеров` показывает последнее смещение + 1 |
| AC-11 | остановить брокер, затем запустить | событие `Error`, после восстановления сообщения снова приходят |
