## Обработка исключений

Компонента рассчитана на работу в серверном контексте и не подразумевает диалога с пользователем.

При возникновении исключительных ситуаций в процедурах компоненты возникает ошибка времени выполнения и выполнение модуля 1С:Предприятия прекращается. 

При возникновении исключительных ситуаций в функциях компоненты выполнение модуля 1С:Предприятия не прекращается. Диагностировать наличие ошибки можно по возвращаемому значению функции:
- для типа булево - значение **Ложь**;
- для типа число (целое и дробное) - значение **-1**;
- для типа строка - **пустая строка**;
- для функций, тип результата которых зависит от параметров (например, `ПолучитьДанныеСообщения`, `ДекодироватьСообщениеAVRO`) - **Неопределено**.

Текст ошибки можно получить функцией **ПолучитьСообщениеОбОшибке**.

Пример:

```1c
Результат = Компонента.УстановитьТаймаутОжидания("не число");
Если Не Результат Тогда
    Сообщить("Ошибка: " + Компонента.ПолучитьСообщениеОбОшибке());
КонецЕсли;

Количество = Компонента.ПолучитьКоличествоСообщенийВПартиции("localhost:9092", "my-topic", 0);
Если Количество = -1 Тогда
    Сообщить("Ошибка: " + Компонента.ПолучитьСообщениеОбОшибке());
КонецЕсли;
```
